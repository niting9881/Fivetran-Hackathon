# Fivetran Connector SDK Hands-On Lab

## 📋 Project Overview

This repository contains the complete implementation of the **Fivetran Connector SDK Hands-On Lab**, demonstrating how to build custom data connectors using Python and deploy them as extensions of Fivetran. The project includes both a sample weather connector and a custom NewsAPI connector, showcasing real-world data integration scenarios.

## 🏗️ Architecture

### High-Level Architecture
```
┌─────────────────┐    ┌──────────────────┐    ┌─────────────────┐
│   Data Sources  │    │  Connector SDK   │    │   Destination   │
│                 │    │                  │    │                 │
│ • NewsAPI       │───▶│ • Python Code    │───▶│ • Snowflake     │
│ • Weather APIs  │    │ • Schema Mgmt    │    │ • BigQuery      │
│ • Custom APIs   │    │ • State Mgmt     │    │ • Others        │
└─────────────────┘    └──────────────────┘    └─────────────────┘
```

### Connector Components
```
connector.py
├── schema()           # Define destination table structure
├── update()           # Main sync logic with state management
├── sync_*()           # Helper methods for specific endpoints
├── get_api_response() # HTTP request handling
└── pagination()       # Handle paginated API responses
```

### Data Flow
1. **Schema Definition**: Define table structures and primary keys
2. **API Authentication**: Use API keys for secure access
3. **Data Extraction**: Fetch data from source APIs with pagination
4. **Data Transformation**: Map API responses to defined schema
5. **State Management**: Track sync progress with checkpoints
6. **Data Loading**: Upsert data to destination warehouse

## 🚀 Quick Start

### Prerequisites
- Python 3.11+ 
- VS Code or preferred IDE
- Fivetran account with API access
- NewsAPI.org account

### Setup Commands
```bash
# 1. Clone repository
git clone https://github.com/YOUR_USERNAME/fivetran-connector-sdk-lab.git
cd fivetran-connector-sdk-lab

# 2. Create virtual environment
python -m venv sdk

# 3. Activate virtual environment (Windows)
sdk\Scripts\activate

# 4. Install Fivetran Connector SDK
pip install fivetran-connector-sdk

# 5. Configure API keys
cp configuration.template.json configuration.json
cp test.env.template test.env
# Edit both files with your actual API keys

# 6. Test connector
fivetran debug --configuration configuration.json
```

## 🔄 State Management

The connector maintains sync state to enable incremental updates:

```json
{
  "to_ts": "2025-10-30T23:13:20"
}
```

This timestamp tracks the last successful sync, ensuring only new data is processed in subsequent runs.
